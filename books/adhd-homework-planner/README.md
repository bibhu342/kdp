## Daily page: each box → one problem
| Problem | Box |
|---|---|
| Focus tug-of-war | Focus Sprints (fill one per 20 min) + Hyperfocus alarm |
| Working memory gaps | Homework "Steps (write them all down)" column |
| Procrastination | Top 3 + tiny 2-minute first step |
| Time blindness | Guess vs Real minutes |
| Mental exhaustion | Recharge First (snack, water, move, quiet) |
| Restlessness | "move!" break between sprints |
| Impulsive mistakes | Before I Hand It In checklist |
| Rejection sensitivity | "If a friend had my day, I'd tell them:" |
| "Lazy" label | Win of the Day + My Reward |
