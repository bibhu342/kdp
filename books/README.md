# Books: index

Every book folder uses the same layout:

| Folder | What's in it |
|---|---|
| `README.md` | Status, KDP IDs, price, print cost, decisions |
| `build/` | Code that makes the PDFs (run from this folder) |
| `source/` or `art/` | Prompts and raw/clean page art (image books) |
| `final/` | **Upload files:** `interior.pdf`, `cover.pdf`, `cover_preview.png`, `LISTING.md` |
| `marketing/` | A+ panels and Pinterest pins (where made) |
| `archive/` | Old samples kept for reference |
